# EnderWatch

One stray glance at an enderman turns it hostile — and most of those
glances are accidents. EnderWatch watches your crosshair and warns you
the moment it lands on an enderman, before it gets angry, so you can
look away while there's still time.

## Features

- **Crosshair enderman warning** — an amber line above the hotbar:
  "Careful — enderman in your sights!" the instant you're looking at
  one
- **Soft warning pling** — a single gentle note-block pling per
  stare, never a nagging loop
- **One-shot per stare** — the sound re-arms only when you look
  away, so staring back plays it exactly once
- **Zero config** — drop it in and play

## Install

1. Install [Fabric Loader](https://fabricmc.net/use/) 0.19.2+ for
   Minecraft 26.2
2. Install [Fabric API](https://modrinth.com/mod/fabric-api) for
   Minecraft 26.2
3. Drop `enderwatch-1.0.0.jar` into your `mods` folder
4. Launch and play — no config needed

## Notes

- Client-side only. Works on any server (including vanilla).
- No mixins, no networking, nothing saved to disk.
